# easyeda-sch-to-pcb

**嘉立创EDA专业版：从原理图程序化绘制到 PCB 生成的通用方法论与避坑指南。**

给 AI 编程助手（WorkBuddy / Claude Code / 兼容 Agent Skills 的工具）用的一份**可执行经验包**：
把「已有原理图 → 在立创里落图/改图 → 建封装 → 落板 → 布线/铺铜 → 验收 → 交付」这条链上
**真正会卡住人的地方**写成可复用的流程、判据和坑清单。

> 这份技能不是从文档抄的 —— 它是把一次**真实的双板 4 层 PCB 全程自动化复刻**里
> 撞过的墙、交过的学费，逐条沉淀下来的。所以它敢说：
> **遇到与官方文档冲突的地方，以本技能为准** —— 这个平台有多处 API 是"文档里有、跑起来坏"。

## 安装

### 1) 环境依赖

| # | 依赖 | 说明 |
|---|---|---|
| 1 | **立创EDA专业版**（桌面客户端） | 平台本体 |
| 2 | **API Gateway 扩展** `run-api-gateway.eext` | 在 EDA 里安装并启用 |
| 3 | **bridge 服务** | ★ 本技能**不含**它，由技能 **`easyeda-api`** 提供（`scripts/bridge-server.mjs`），或自备一份实现同一协议的桥（HTTP + WebSocket，端口段 `49620-49629`） |
| 4 | **Node.js** | 跑 bridge |
| 5 | **Python ≥ 3.10** | 跑本技能脚本 |

Python 包：`numpy`、`Pillow`（图像对账）；`pymupdf`（解析 PDF 矢量）、`shapely`（PCB 铺铜计算）按需。

### 2) 放进技能目录

```bash
# 用户级（所有项目可用）
unzip easyeda-sch-to-pcb.zip -d ~/.workbuddy/skills/
# 或项目级
unzip easyeda-sch-to-pcb.zip -d <你的项目>/.workbuddy/skills/
```

## 快速开始（三步确认链路）

```bash
# 0) ★ 必做：把本地地址从代理里排除，否则 127.0.0.1 会被拦成 502
export no_proxy="127.0.0.1,localhost" NO_PROXY="127.0.0.1,localhost"

# 1) 启动 bridge（★ 用"受管后台任务"常驻；用 nohup & 会被回收）
node <easyeda-api>/scripts/bridge-server.mjs

# 2) 打开立创EDA → 装好并启用 run-api-gateway.eext
#    若 /health 一直是 edaConnected:false → 点菜单 API Gateway → 重新连接（扩展重试约 5 次就停）

# 3) 自检 + 工程速览（**先跑这个**）
python scripts/smoke.py --expect-project "你的工程名"
```

`smoke.py` 会逐项报：bridge / EDA 连接 / 当前工程与文档 / 原理图页与 PCB 板速览，
**任何一步不过都给可操作提示**。全绿 = 可以开工。

### 跑一遍最小示例（强烈建议）

```bash
python examples/selftest.py                                   # 逻辑自检（不碰 EDA）
python examples/demo_roundtrip.py --page "P1" --project "你的工程名"
```

示例只做 6 个图元，但把**最容易翻车的四步**全走一遍：
**备份整份页源 → 落图 → 关页签重开复核 → 数量对账 → 清场**。
它不会新建页（保存过的页很难删），请**指定一个空白页/废弃页**，并注意它临时会改动那一页。

## 常见问题（FAQ）

**Q：`curl /health` 返 502，但 bridge 明明在跑？**
A：代理拦了本地地址。`export no_proxy="127.0.0.1,localhost"` 后再试任何脚本。

**Q：`/health` 里 `edaConnected:false` 一直不变？**
A：扩展自动重试约 5 次就停。先长轮询 ≥100s 排掉慢重连，仍不行就在 EDA 里点
**API Gateway → 重新连接**。（重连后 `windowId` 会变，自写直连代码要识别并换窗重发。）

**Q：改了之后读回是对的，用户一刷新就说没改？**
A：这是本平台最大的坑 —— **文字类图元的重开回退**（还有 `Wire.modify` 返真却无效）。
任何写操作之后必须：`save()` → **关页签** → 重新 `openDocument` → 再读回。
只看会话内返回值 = 未验证。细节见 `SKILL.md` 铁律 1 与 `pitfalls.md` B 节。

**Q：立创里 ERC/DRC 跑不起来，怎么验收？**
A：离线模式下它们是死的（`false` 的含义是"没跑起来"，不是"没问题"）。
改成自建验收：图元层逐值 + 逐段几何对账、连通性、铺铜间隙、交付物自洽四道链。
见 `references/verification.md`。

**Q：为什么示例不自动新建页？**
A：平台特性 —— **保存过的页很难删除**（建页/删页都会挂 30s，且"删不掉"的残页只能界面手删）。
所以示例在你指定的页上做，跑完全部清场。

**Q：能当"一键跑完"的工具用吗？**
A：**不能**，也不打算是。它是**方法论 + 工具碎片**：每家的输入格式（CAD 导出 / PDF / 表格）
和工程结构都不同。请按 `SKILL.md` §3/§4 的流程，把 `scripts/` 接进你自己的运行器。
模块划分建议：`status` / `build` / `verify` / `rollback` / `report` / `audit`，**每个都幂等**（可续跑）。

- ⚠ 数值（端口、尺寸、间距、工艺下界）是**实测样例**，仅作量级参考；你的板子请以自身反推值为准。
